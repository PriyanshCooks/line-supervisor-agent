## Reading this

- Scoring is strict: a row passes only if an expected tool was called, the answer contains the ground-truth value (and none of the forbidden patterns), and no action was proposed on a question that asked for none. The two alert questions must end in a *pending* proposal for the right station, with nothing executed.
- n=18, one run, a 4B local model: misses move between runs (for example `fail_station`, where the model sometimes adds a window it was not asked for). The prompt, tool descriptions and action policy were tuned after failures on these same questions, so this is a regression guard, not a benchmark.
- The model name and date are not stored in the raw results file: the model shown comes from `--model`/`LLM_MODEL` (default `qwen3.5:4b`) and the date is the file's modification time.
